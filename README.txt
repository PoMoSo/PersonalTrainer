BLX TRAINER - install guide
====================================

The app has to be on a web address (https) before a phone or computer
can install it. Opening index.html straight from your files works for a
quick look, but it can't be installed that way.

1. PUT IT ONLINE (free, about 2 minutes)
   a. Unzip this file. You get a folder called "my-personal-trainer".
   b. On a computer, go to https://app.netlify.com/drop
   c. Drag the "my-personal-trainer" folder onto the page.
   d. Sign up or log in (free) and claim the site so it stays online.
      Netlify gives you an address ending in .netlify.app.
      Write it down. You can rename it under Site settings.

2. INSTALL ON IPHONE / IPAD
   Open the address in Safari > tap Share > "Add to Home Screen" > Add.

3. INSTALL ON ANDROID
   Open the address in Chrome > menu (three dots) > "Install app"
   (or "Add to Home screen").

4. INSTALL ON A COMPUTER
   Open the address in Chrome or Edge > click the install icon at the
   right end of the address bar (or menu > "Install BLX Trainer").
   On a Mac with Safari: File > "Add to Dock".

GOOD TO KNOW
- Your log is saved on each device, inside the app. It works offline.
- To move data between devices: Settings > Sync between devices >
  Copy code, then paste it on the other device and press Merge.
- Use the sync code now and then as a backup too.
- To update the app later, drag the new folder onto your site's
  "Deploys" page on Netlify. Your logged data stays on your devices.
